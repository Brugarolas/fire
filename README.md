This is Napalm programming language. It is a new scripting language inspired by Wren and TypeScript. While this is a toy programming language, one of it's design objectives it is to be fast. To achieve that, it is NOT an interpreted programming languaged, it is just JIT compiled using Cranelift. It uses StickyImmix garbage collector by MMTk, and other high-performance crates like smallvec for some Vecs, Logos, ahash for HashMap, mimalloc for general purpose allocator, rclite for Rc, hybrid-rc for Arc or parking_lot for RwLock.
